Java lab exercises covering language fundamentals, object-oriented programming,
interfaces, desktop applications, and database access.

| Lab | Topics |
| --- | --- |
| [TP1](Java/TP1) | Basic calculations and methods |
| [TP2](Java/TP2) | Arrays, strings, and control flow |
| [TP3](Java/TP3) | Classes, objects, and inheritance |
| [TP4](Java/TP4) | Inheritance, polymorphism, and assertion checks |
| [TP5](Java/TP5) | Abstract classes and interfaces |
| [TP6](Java/TP6) | Swing calculator and MySQL product management |

TP6 requires Java 17+, Maven, and a running MySQL server. Run the product window
using `bash Java/TP6/run-exercise2.sh` after configuring your local database
environment variables. A graphical Java runtime and display are required.

Keep passwords in your local environment. Database files, build outputs, and
generated analysis artifacts are excluded from version control.
