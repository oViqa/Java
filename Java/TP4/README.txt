TP4 - Heritage en Java
======================
Contenu : rapport PDF, dossier src (8 fichiers Java), resultats_execution.txt.
Prerequis : JDK 8 ou superieur. Aucune dependance externe.
Depuis le dossier TP4 :
  mkdir bin
  javac -encoding UTF-8 -d bin src/*.java
  java -cp bin Main
Sous Windows, les memes commandes fonctionnent dans un terminal avec le JDK configure.
Les exercices 1 et 3 correspondent a la numerotation de l'enonce fourni.
Employe est ecrit sans accent pour simplifier les noms de fichiers.
Les donnees utilisees sont fictives. Les tests sont reproductibles en relancant Main.
